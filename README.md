## 制作目的

製造現場で使用する粉末材料の在庫を、  
紙やExcelだけに依存せず管理できるようにすることを目的として制作しました。

実際の製造業務を意識し、  
入庫・出庫・在庫一覧・履歴管理・マスター管理まで実装しています。

## 主な機能

- 在庫登録
- 在庫一覧表示
- 在庫編集
- 在庫削除
- 入庫処理
- 入庫履歴
- 出庫処理
- 出庫履歴
- 出庫取消
- 粉末マスター管理
- 作業者マスター管理
- SQLiteによるデータ保存

## 使用技術

- Java 21
- JavaFX 21
- SQLite
- JDBC
- Eclipse
- jpackage
- WiX Toolset

## 工夫した点

- 在庫ごとにIDを持たせて管理
- 出庫時に数量・重量を自動更新
- 出庫取消時に在庫数を元に戻す処理を実装
- 入出庫履歴をSQLiteへ保存
- アプリを終了してもデータが残るように永続化
- Windows用EXEとして実行可能な状態まで作成
- jpackage / WiX Toolsetを使用してWindows用インストーラーを作成

## データ保存

SQLiteを使用しています。

実行時のデータベースは、ユーザーごとのローカル領域に保存されます。

`C:\Users\ユーザー名\AppData\Local\ZaikoApp\zaiko.db`

## 今後追加したい機能

現在は基本的な在庫管理機能を中心に実装しています。
今後は、より実際の製造現場で使いやすいシステムを目指して、
以下の機能を追加していきたいと考えています。

- 品名・ロット番号などによる検索／絞り込み機能
- CSV / Excelへのデータ出力
- データベースのバックアップ・復元機能
- ログイン機能
- 管理者・一般作業者などの権限管理
- 入出庫データの集計・グラフ表示
- 日付や期間を指定した履歴検索
- 操作履歴（誰が・いつ・何を変更したか）の記録
- 誤操作防止のための確認画面・入力チェック強化

- アプリの自動アップデート機能

将来的には、SQLiteによるローカル管理だけでなく、
サーバーやクラウド上のデータベースを利用して、
複数の作業者が同じ在庫情報を共有できるシステムにも発展させたいと考えています。

## 制作について

本アプリは、Javaを学習し始めた初心者として制作したポートフォリオ作品です。

プログラミング経験がまだ浅いため、
設計方法、Javaのコード作成、エラーの原因調査などでは
生成AI（ChatGPT）を積極的に活用しながら開発を進めました。

特にコードについてはAIから提案された内容を多く活用しています。

一方で、単純にコードを生成して終了するのではなく、

- 自分の製造業経験から必要な機能を考える
- 在庫管理の仕様を決める
- 生成されたコードをEclipseへ実装する
- 実際に動作確認する
- エラー内容を確認して修正する
- 入庫・出庫・履歴・取消などの機能を追加する
- SQLiteによるデータ保存を実装する
- JavaFXアプリをWindows向けにパッケージ化する
- jpackage / WiXを使用してインストーラーを作成する

といった工程を繰り返しながら完成させました。

制作を通して、
Javaの基本構文だけでなく、
クラスの役割、データベース接続、SQL、例外処理、
デバッグ、アプリケーションの配布方法などについて学ぶことができました。

現時点では、AIの支援なしですべてのコードを一から書けるレベルではありません。

今後は、このアプリで使用しているコードを一つずつ理解し、
自分自身で設計・実装・修正できる範囲を増やしていくことを目標としています。
